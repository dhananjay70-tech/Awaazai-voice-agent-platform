# 4. Product Vision

AwaazAI is a platform where users can create, configure, test, and eventually deploy their own AI voice agents.

The primary user journey must be:

1. Sign up or log in.
2. Open the dashboard.
3. Create an AI voice agent.
4. Configure its personality and system prompt.
5. Select its language and voice.
6. Configure its first message and conversation behavior.
7. Test the agent in a live voice playground.
8. Speak naturally and hear the agent respond.
9. View the conversation transcript.
10. Save and revisit conversations when supported by the backend.
11. Manage agents from a dedicated agent workspace.

The product should feel like a real developer-oriented SaaS platform, not a static portfolio, a generic admin template, or a collection of disconnected mockup pages.

The primary focus is the **Agent Studio and real-time voice playground**.
